Multi-pass describing

A single clip described incrementally: the structural caption (diarized turns, timestamps, non-speech scene) first, then word stress and intonation, per-turn emotion, speaker profile, and acoustic dynamics.

2 · Understanding: describe, then reason

The description is read by a frozen text-only reasoner that never hears the audio, so downstream accuracy measures how much the description actually captures.

Describe-then-reason on spoken audio

Five clips where the evidence for the answer is present in the description: the model's structured description, and the answer a frozen reasoner picks from that description alone (speaker counting, turn counting, non-speech sound, accent, age).

The same structured description is renderable. A text-to-audio generator conditioned on it gives explicit, zero-shot control over word-level emphasis directly from the caption text.
