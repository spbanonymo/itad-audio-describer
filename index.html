Iterative Timestamped Audio Describer

A perception foundation model that turns raw audio into an explicit, timestamped, speaker-attributed structured description — then reasons and generates from that description alone.

We decouple perception from reasoning. The describer writes what it hears as a readable schema (events, timings, transcript, speaker profile, stress, emotion, acoustics), built up one pass at a time. A frozen text-only model then answers questions from the description, and a generator renders the same description back into controllable audio. Each card below opens a live, audio-synced viewer.

1 · The Describer: iterative structured perception

One clip, described pass by pass. A structural caption is written first, then each speech attribute is layered on, each pass conditioned on the previous output through the Instruction-Input-Output format.

2 · Generation: description → controllable audio

The same structured description is renderable. A text-to-audio generator conditioned on it reproduces event timing and gives explicit, zero-shot control over emphasis and speaker attributes.

Temporal grounding

Events land at the stated times

Audio generated from a caption places each event at its timestamp. Two frame-level localizers (FLAM, PE-A-Frame) compare against a no-timestamp baseline, with the original recording as reference.
